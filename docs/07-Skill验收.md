## 交付范围

| 能力 | 当前行为 |
| --- | --- |
| Skill | 从想法设计、理解已有系统、查询已有设计、维护设计迭代；主文件按任务路由参考资料 |
| query | 模型/画布索引、文本/来源搜索、视图/节点/字段读取、一跳关系及直接子节点；有界输出与分页 |
| validate / render | 原模型完整结构/流程校验；画布结构/布局/层级校验；生成自包含离线 HTML |
| diff | 基于稳定 ID 的字段差异，区分内容/布局/revision；不输出整段新旧正文 |
| apply | 完整校验并生成后检查基线，应用候选与 HTML；普通写入失败尝试恢复 |
| install | 拷贝独立运行所需文件，不携带测试、POC、node_modules 或开发产物；拒绝覆盖已有目录 |

主文件 4,083 字节；安装内容 24 个文件、171,980 字节（不含 npm 依赖）。唯一直接运行依赖仍是 Ajv，没有服务、数据库、构建步骤或 AI API。依赖首次安装需可访问 npm 源，日常运行和生成的 HTML 可离线使用。文件数与大小是本次快照，不是未来版本上限。

## 查询规模实测

本机 Node 进程内查询一份合成模型：10,001 个节点（含根）、输入 JSON 10,377,074 字节，每种查询运行五次取中位数：

| 查询 | 中位耗时 | 返回 UTF-8 字节 | 返回范围 |
| --- | ---: | ---: | --- |
| 模块索引 | 32.83 ms | 5,488 | 首20项，显式下一页 |
| 精确文本筛选 | 38.67 ms | 689 | 1个命中摘要 |
| 指定节点 | 22.33 ms | 1,546 | 目标语义详情，无递归展开 |

报告位于本地 `.artifacts/skill-acceptance/query-benchmark.json`。耗时不含文件解析和进程启动，受机器与运行状态影响；默认上限是 12,000 UTF-8 字节，不是 token。查询会读取整个 JSON 到本地内存，但只把筛选后的有界输出交给 AI。结果不代表画布万节点性能、自然语言检索准确率或无限规模支持。

## 保留的边界

- 查询只限制本工具的返回字节和项数，不控制 AI 其他工具或整段会话总上下文。partial、truncatedPaths 和 nextOffset 都需要处理；摘要不是完整语义。
- 代码来源由 AI 实际读取后记录，生成器不自动分析仓库、不持续核验代码或证明实现已测试。
- diff 是结构化字段变化，不自动证明业务影响完整；画布不显示浏览器内变更红线。
- 画布一次显示一层模块，不是全层同时 LOD；复杂自动排版、大图渲染、浏览器内容编辑后置。
- apply 保留基线与候选，普通失败尝试恢复；不承诺断电恢复或多个发布进程的事务一致性。
- 真实业务准确性、长期维护成本、客户端自动发现和用户使用效果仍需实际会话持续观察。
