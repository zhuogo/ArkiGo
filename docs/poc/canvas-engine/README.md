## 职责分工

2026-11-14 增加[实现情况](implementation.html)：用 ArkiGo 当前的局部源码范围展示四种状态、实现说明与来源，以及缺省未核对的行为。输入为 `implementation.canvas.json`。旧演示未补写实现结论，重新生成后显示未核对；不把原有设计示例标为已经实现。

1. AI 读取用户想法或当前任务所需的代码，组织系统职责、关系、来源和待决策问题。
2. AI 输出画布 JSON；已有设计模型也可直接交给适配器提供默认布局。
3. `render.mjs` 校验并将数据、公共样式及运行时打包为 HTML。
4. 浏览器引擎负责探索、搜索、主题切换、拖动与布局保存。拖动不会改写设计内容。

分区、节点数、坐标和关系来自 JSON。生成器不扫描仓库；代码来源由 AI 实际读取后记录。`registration.canvas.json` 的页面标题为“用户注册”，展示四级模块树；`arkigo.canvas.json` 展示分区架构；`tasks.canvas.json` 的新增流程展示横向主线和下方异常分支。

`arkigo-canvas/1` 保留原字段，新增可选 `rootViewId`，省略时取第一个视图。节点的 `targetViewId` 表示唯一子视图归属；校验拒绝自指、循环、多父、根有父节点与不可达视图。跨模块业务关系仍由连线表达。

走读界面与执行行为已移除。旧输入的 `walkthrough` 字段继续兼容并校验引用，浏览器不展示或执行；新输入可写 `walkthrough: []`。此次界面调整不更改其他 Schema 字段。

页头保持 56px 单行工具栏，仅保留层级面包屑、纯图标搜索入口与浅色/深色切换图标，已移除独立返回箭头、Tabs、视图选择框与走读入口。首次打开跟随系统主题；手动切换后在浏览器存储可用时记住选择。搜索图标打开节点目录；选中带子视图的模块后，底部提供进入与详情按钮，避免立即打开详情遮挡画布，导出仍在目录底部。

选择模块后可点击进入、双击或放大进入；像浏览文件夹一样点击上一级或任意祖先面包屑返回，也可缩小到返回阈值或使用 `Alt+Left`。父级相机和模块选中随导航保存/恢复。放大依据选中模块的屏幕投影大小、可见性和主动输入判断；滚轮/双指每次手势最多跨一级。搜索与适应只定位当前层，不自动进入。

## 动态效果边界

- 普通平移、缩放和拖动直接响应，不添加弹簧或惯性。跨层进入/返回使用 230ms 空间展开/收回，子视图从所属模块卡片的位置衔接；键盘操作和减少动态效果偏好下立即完成。
- 网格保持固定的屏幕间距，不随层级相机突然重铺；动画仅在过渡期间保留合成提示，结束后清理。
- 指针打开浮动面板时提供 180ms 的淡入与轻微位移；关闭立即响应。不会逐个播放节点入场。
- 键盘触发操作关闭控件过渡；减少动态效果偏好保留短淡入，关闭位移与按压缩放。
- 悬浮和选中样式相互独立，选中对象的描边不被 hover 覆盖。节点、按钮及数字区域不会因状态变化改变尺寸。
- 提示不拦截鼠标，不遮挡右下角画布控制；手机也可从目录底部导出布局。

## 已验证与未验证

本次主题切换、纯图标入口、移除走读及独立返回箭头的回归通过。主题覆盖首次跟随系统、双向手动切换、刷新首帧恢复、手动偏好优先和存储不可用。84 项 Node 测试、基础 Playwright Chromium 回归和 10 项模块导航场景通过。已检查点击/双击、滚轮/双指自动进退、单手势一级、父级相机/焦点恢复、深链及损坏地址、过渡中断、键盘/减少动态效果、窗口变化、取消拖动，以及实际逐帧进入/返回的透明度、相机和旧场景清理。320–1440px 单行工具栏、320/375px 深层面包屑与操作栏、桌面、系统深色模式、详情、搜索、布局保存/回放及手机导出均已检查。截图与导航报告在 `.artifacts/canvas-engine/`。闪烁修复前后的真实合成帧与 RAF 采样保存在其 `semantic/` 子目录；修复后退出层透明度保持递减，未观察到旧画面恢复。

当前每次只渲染一个活动层级，切换时临时保留旧场景用于过渡。这是模块钻取式语义导航，尚未实现所有层级同时 LOD、关系聚合或无限图性能保证。

触控检查使用浏览器模拟，尚无物理手机验收；用户阅读体验、新会话建模稳定性和大图性能仍需后续验证。完整命令与范围见 [POC 记录](../README.md) 和 [画布输入指引](../../../skills/arkigo/references/canvas.md)。
